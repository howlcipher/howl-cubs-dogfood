Integrity rules (the existing guards apply to this page too):
- Every rendered number is a value copied by the export from research/*.json by JSON pointer, tagged data-src="file#pointer", shown in the shared display format with a full-value <details>. The export never computes, rounds or derives a statistic. The DOM scan must cover this page.
- Text quoted from research/*.md is copied by the export verbatim, by exact line match, with its file and line recorded as its source; a test fails if the line is no longer present verbatim.
- Do not edit research/ or data/. Do not invent values or wording that states a result.
- No model values by default (spec rule 3): do not show predicted P(safe), mean_p_safe, flagged hold counts, runs left values, or any Cubs model value outside the elements named below. Extend the default-visible pointer allowlist test to this page.

Page content, in this order:
1. Verdict panel: the primary verdict (sendhold_experiment.json /verdict) followed directly by its meaning from meanings.json, then the pre-registered v2-definition verdict (/verdict_v2_preregistered_definition), with the same unmapped-verdict alert guard as the Overview.
2. Criteria tables, one per analysis in sendhold_experiment.json /analyses (v3_primary, v2_preregistered, v3_ambiguous_as_safe, v3_fallback_dropped), each with a caption naming the analysis and its /verdict. Rows: Brier vs constant, calibration slope, runs left, negative control. Each row shows the published estimate, its 95% interval beside it (interval_95 lower and upper), "Met" or "Not met" in text from /passed, the rule text from /rule, and its role. Roles are fixed display copy kept in the export next to MEANINGS (not derived): Brier vs constant = gating; calibration slope = gating; negative control = control; runs left = effect (only read when the gating criteria are met).
   - The runs-left row shows the text "Not interpretable under the NEGATIVE verdict" when that analysis's verdict is NEGATIVE; its estimate, interval and Met/Not met go inside a <details> labeled "Failed-model value (not for decisions)".
   - Under each table: "The verdict follows the pre-registered gating rule, not a count of passes."
   - Beside the Brier row: "The model did not beat a constant guess; the interval includes zero, so this is no evidence of benefit, not evidence of harm. Passing diagnostic rows do not change the verdict."
